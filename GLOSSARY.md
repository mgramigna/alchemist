# Alchemist

A tool for designing homebrew Scripts for Blood on the Clocktower, made up of Custom Characters. Alchemist is not affiliated with The Pandemonium Institute.

## Language

### Scripts

**Script**:
A named, authored collection of Characters that a group plays Blood on the Clocktower with.
_Avoid_: Edition, set, project

**Script Owner**:
The Alchemist user who owns a Script and alone can edit it. Ownership is independent of the Script's Author Credit.
_Avoid_: Author (when referring to editing rights)

**Author Credit**:
The editable attribution on a Script, shown on shared pages and included in exports. It starts with the Script Owner's display name and remains independent of later display name changes.
_Avoid_: Owner (when referring to attribution)

**Image Credit**:
Optional attribution for an uploaded Character icon, Script logo or Script background, such as a CC BY icon's creator, source and license. The shared page lists the credits of images it currently shows, and printed sheets link there rather than printing each credit.
_Avoid_: Author Credit (which credits the Script's author), Attribution (UI copy only)

### Characters

**Character**:
An entry on a Script that a player can be or a Storyteller can use, with an ability and a Team.
_Avoid_: Role, card

**Custom Character**:
A Character designed in Alchemist rather than published by The Pandemonium Institute.
_Avoid_: Homebrew character (UI copy only)

**Official Character**:
A Character published by The Pandemonium Institute and referenced by its ID alone.

**Team**:
The category a Character belongs to: Townsfolk, Outsider, Minion, Demon, Traveller, Fabled, or Loric.
_Avoid_: Type, character type, class

**Alignment**:
Whether a Character plays for Good or Evil. It defaults from the Team, and Travellers have none until the game assigns one.
_Avoid_: Side, faction

**Reminder Token**:
A labeled marker associated with a Character that a Storyteller uses to track game information.
_Avoid_: Night reminder, Night Instructions

**Global Reminder Token**:
A Reminder Token available even when its associated Character is not in play.

**Jinx**:
A rule explaining how two particular Characters interact when they appear on the same Script.

### Nights

**Night Order**:
The ordered sequence of Storyteller actions for a Script's First Night or Other Nights.
_Avoid_: Wake order

**Night Instructions**:
The directions for resolving a Custom Character's night action, with separate text for First Night and Other Nights.
_Avoid_: Reminder tokens
